Privacy Policy

kanal uploader is a private tool used solely by the owner of one YouTube channel to upload and manage that channel's own videos via the YouTube Data API.

  • It accesses only the owner's own YouTube channel, with the owner's consent (OAuth 2.0).
  • It does not collect, store, sell or share personal data of any other user.
  • OAuth credentials are stored encrypted as GitHub Actions secrets and are used only to upload, update, delete and set thumbnails for the owner's own videos.
  • Access can be revoked at any time at myaccount.google.com/permissions.
  • This tool uses YouTube API Services. See the Google Privacy Policy and the YouTube Terms of Service.

Contact: open an issue at github.com/abinitiomao-lang/kanal.
